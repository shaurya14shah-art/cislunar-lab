# Data

* `mc/` - raw Monte Carlo outcome tables (one `.npz` per halo, plus robustness and joint-error runs), about 50 MB.
  Not tracked by git because of its size; it ships alongside the repository and is regenerated by
  `python scripts/run_experiment.py` (fixed seed, about two hours on two cores).
* `mc_summary.json` - the analysed results the paper and the interface read (`scripts/analyze_experiment.py`).
* `route_study.json` - all-routes check (`scripts/route_study.py`).
* `figure_numbers.json` - a few numbers computed while drawing figures.
* `mc_summary_v1_uneven_sampling.json` - summary of the FIRST run, kept for the record: it used uneven manifold
  sampling and must not be used for results (see `docs/DECISIONS.md`, entry 21).
* `mc_run.log` - log of the final run.
